BIM OpenNotebook

A lab notebook for building models: ask in plain language, keep every answer as evidence you can recheck.

A notebook records a session with an AI agent about a building model. Each turn is a request written in plain language and the agent's reply: its text, the tools it called, and the results it produced, such as a number, a table, a chart, the dataflow graph that computed them, or a 3D view. There are no code cells. Every result keeps a snapshot, so a notebook opens with no server; a result backed by a graph can be re-evaluated against a running host, which says whether it changed.

This site is a static copy: it shows each notebook as it was saved. Asking new questions, Re-evaluate, and the live 3D view need the host from BIM Open Toolkit. None of these samples is a recording of a live agent run yet: the three NRC notebooks were generated from written outlines against a running host, and the other nine are sessions an agent played out; in all of them the host computed every number shown in a table, value, or chart.
